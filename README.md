# My Portfolio

A modern React portfolio built with Vite and Tailwind CSS.

## Features

- **Vite** for fast development and optimized builds
- **React** for component-based UI
- **Tailwind CSS** for utility-first styling
- **Google Fonts** integration (Playfair Display, JetBrains Mono)
- **Custom color palette** with warm cream tones and semantic status colors
- **Sticky navigation** with smooth scrolling
- **Responsive design** ready for all screen sizes

## Project Structure

```
src/
  components/
    Nav.jsx          - Sticky navigation bar
    Hero.jsx         - Hero section
    Toolkit.jsx      - Skills/toolkit section
    Projects.jsx     - Portfolio projects
    Journey.jsx      - Journey/experience section
    Connect.jsx      - Contact/connect section
  App.jsx            - Main app component
  index.css          - Global styles & CSS variables
  main.jsx           - React entry point
```

## Color Palette

- **Background**: Warm Cream `#F5F0E8`
- **Surface**: `#EDE8DF`
- **Border**: `#D4C9B8`
- **Text Primary**: `#2C2A27`
- **Text Secondary**: `#7A736A`
- **Badge/Tag**: `#E0D9CC`
- **Status Done**: `#C8D8C0` (dusty green)
- **Status In Progress**: `#D8CCBA` (warm sand)
- **Status Paused**: `#DDD5C8` (stone grey)

## Getting Started

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

## Typography

- **Headings**: Playfair Display (serif)
- **Mono/Labels**: JetBrains Mono (monospace)
